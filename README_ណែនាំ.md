# កម្មវិធីគ្រប់គ្រងកាតសិស្ស (ទូរសព្ទ + កុំព្យូទ័រ)

កម្មវិធីនេះជា PWA ដំឡើងបានដូចកម្មវិធីធម្មតា មានរូបតំណាងលើអេក្រង់ ហើយដំណើរការបានដោយគ្មានអ៊ីនធឺណិត។
ទិន្នន័យសិស្សរក្សាទុកក្នុងឧបករណ៍នីមួយៗ មិនឡើងទៅម៉ាស៊ីនមេទេ។

## ឯកសារក្នុងកញ្ចប់
- index.html (កម្មវិធី), manifest.webmanifest, sw.js, ថត icons/ ។ ត្រូវដាក់ឯកសារទាំងនេះជាមួយគ្នា។

## ជំហាន ០៖ រក្សាទិន្នន័យចាស់ (ប្រសិនបើមាន)
1. បើក `index.html` ថ្មីនេះដោយចុចពីរដងក្នុងថតកុំព្យូទ័រ (ដូចដែលអ្នកធ្លាប់ធ្វើ)។ ទិន្នន័យចាស់នឹងបង្ហាញដោយស្វ័យប្រវត្តិ។
2. ចូល ការកំណត់ ➜ "បម្រុងទុកនិងផ្ទេរទិន្នន័យ" ➜ ចុច "បម្រុងទុក (.json)"។ ទុកឯកសារនេះឱ្យល្អ។

## ជំហាន ១៖ ដាក់កម្មវិធីលើគេហទំព័រឥតគិតថ្លៃ (ធ្វើម្តង)
ការដំឡើងជាកម្មវិធីតម្រូវឱ្យមានតំណ HTTPS។ វិធីឥតគិតថ្លៃមួយគឺ GitHub Pages (ទាមទារគណនី GitHub ឥតគិតថ្លៃ)៖
1. ចុះឈ្មោះ github.com ➜ New repository ➜ ដាក់ឈ្មោះ (ឧ. `cards`) ➜ Public ➜ Create។
2. ចុច "uploading an existing file" ហើយអូសឯកសារ និងថត icons ទាំងអស់ចូល ➜ Commit changes។
3. Settings ➜ Pages ➜ Source: Deploy from a branch ➜ Branch: main / (root) ➜ Save។
4. រង់ចាំ ១-២ នាទី នឹងមានតំណ ដូចជា `https://ឈ្មោះអ្នក.github.io/cards/`។ ដាក់តំណនេះក្នុង Chrome។
(អ្នកអាចប្រើ Netlify ឬ Cloudflare Pages ជំនួសបាន។ ទាំងនេះជាសេវាកម្មខាងក្រៅ ដែលអាចផ្លាស់ប្តូរការដំឡើង។)

## ជំហាន ២៖ ដំឡើងលើឧបករណ៍នីមួយៗ
- **Android (Chrome)៖** បើកតំណ ➜ ម៉ឺនុយ ⋮ ➜ Install app (ឬ Add to Home screen)។
- **កុំព្យូទ័រ (Chrome/Edge)៖** ចុចរូបដំឡើងក្នុងរបារអាសយដ្ឋាន ឬ ម៉ឺនុយ ➜ Install។
- **iPhone/iPad (Safari)៖** ចុច Share ➜ Add to Home Screen។
- ក្នុងកម្មវិធី ការកំណត់ ➜ "កម្មវិធីលើទូរសព្ទ/កុំព្យូទ័រ" ក៏មានប៊ូតុងដំឡើងដែរ។

## ជំហាន ៣៖ ដាក់ទិន្នន័យចូលម៉ាស៊ីនថ្មី
បើកកម្មវិធីដែលបានដំឡើង ➜ ការកំណត់ ➜ "ស្ដារពីឯកសារបម្រុងទុក" ➜ ជ្រើសឯកសារ .json។
ដើម្បីផ្ទេរពីទូរសព្ទទៅកុំព្យូទ័រ (ឬបញ្ច្រាស) សូមបម្រុងទុក ផ្ញើឯកសារតាម Telegram/USB រួចស្ដារ។
(ការស្ដារជំនួសទិន្នន័យបច្ចុប្បន្ន។ ពាក្យសម្ងាត់មិនរួមក្នុងឯកសារបម្រុងទុកទេ។)

## ចំណាំសំខាន់
- ទិន្នន័យមិនធ្វើសមកាលកម្មដោយស្វ័យប្រវត្តិរវាងឧបករណ៍ទេ។ សូមបម្រុងទុកជាប្រចាំ ជាពិសេសមុនលុបកម្មវិធី ឬសម្អាតទិន្នន័យកម្មវិធីរុករក។
- លើទូរសព្ទ ពុម្ព Khmer OS ជាធម្មតាមិនមានទេ ដូច្នេះប្រើ Moul/Siemreap ពី Google ជំនួស (ត្រូវការអ៊ីនធឺណិតម្តងដំបូង រួចវារក្សាទុកក្នុងឧបករណ៍)។ លើកុំព្យូទ័រដែលដំឡើង Khmer OS វាប្រើពុម្ពនោះ។
- បោះពុម្ព៖ ក្នុងកម្មវិធី Chrome ចុច "បោះពុម្ព / PDF" ហើយបើក "Background graphics"។ លើទូរសព្ទ អ្នកអាចរក្សាជា PDF រួចបោះពុម្ពពីកុំព្យូទ័រ។
- Excel៖ ទទួលតែ .xlsx និង .csv (មិនទទួល .xls ចាស់ទេ)។ ក្រឡាថ្ងៃខែជាលេខ Excel ត្រូវបំប្លែងជា dd/mm/yyyy។
- ពេលអ្នកជំនួស index.html ដោយកំណែថ្មី សូមបើកកម្មវិធីពីរដង ដើម្បីឱ្យកំណែថ្មីចាប់ផ្តើម។
